# Торғай тынысы

«Торғай тынысы» аудандық қоғамдық-саяси газетінің электронды мұрағаты.

## Технологиялар
- React 18
- Vite 6
- Lucide React

## Іске қосу
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```
